INOMOTO ホームページ（元素材を変更しない版）

1. index.html をダブルクリックしてブラウザで表示してください。
2. 1枚目の元SVGは assets/character.svg、2枚目の元SVGは assets/name.svg として無変更で収録しています。
3. 背景は添付の3枚目 assets/background.png をそのまま使っています。新しい画像生成はしていません。
4. CSSアニメーションは style.css の @keyframes character-float / name-float / bg-drift で変更できます。
5. WORKSのカードは仮表示です。自分の作品画像に差し替えてください。
6. CONTACTのX/BOOTHリンクは仮URLです。公開前に正しいリンクへ変更してください。
7. GitHub Pagesにアップロードする場合は、フォルダ内の index.html, style.css, script.js, assets を同じ階層でアップロードしてください。

※SVGはどちらも1920×1080のキャンバスなので、サイト上では同じ位置に重ねています。素材の位置を変更したい場合は style.css の .name-art / .character-art を調整してください。
