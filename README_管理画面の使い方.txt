【使い方】
1. このZIPを解凍します。
2. admin.html をChrome/Edgeで開きます。
3. 「ホームページのフォルダーを選ぶ」で解凍した inomoto-website フォルダーを選びます。
4. 文章や作品カード、画像、リンクを編集します。
5. 「プレビューを見る」で確認します。
6. 「編集したホームページをZIPで書き出す」をクリックします。
7. 書き出したZIPを解凍してindex.htmlを開きます。
※編集内容は管理画面の中だけでは保存されません。編集後は必ずZIPを書き出してください。
※ファイルは外部サーバーへ送信しません。
※管理画面の表示にはChromeまたはEdgeの最新版を推奨します。

【今回の追加機能】
・WORKSで「＋ 作品を追加」すると、最新の作品が先頭に表示されます。
・WORKS / ORIGINAL WORKの作品説明欄はHTML装飾に対応しています。
　例：<strong>太字</strong>、<a href="https://example.com">リンク</a>、<br>改行
・説明欄の装飾ボタンを押すと選択した文字をタグで囲めます。
・安全のため、説明欄では使用可能なHTMLタグとリンク先を制限しています。

【作品詳細ポップアップ】
WORKS / ORIGINAL WORK の各作品をクリックすると詳細ウィンドウが開きます。管理画面の各作品にある「詳細説明」と「＋ 詳細画像を追加」で編集できます。詳細画像は複数登録・削除できます。ZIPを書き出して公開用ファイルに反映してください。

【v16 ORDER詳細ポップアップの文章装飾】
・ZIPを解凍して、admin.html を Chrome / Edge で開いてください。
・①でホームページフォルダー（inomoto-website）を選択し、ORDERタブを開きます。
・制作内容／制作の流れ／料金・納期の「説明」と各詳細項目の「説明」を編集できます。
・Enterキーで改行できます（HTMLタグを書かなくても公開ページに改行が反映されます）。
・文字を選択した状態で「太字」「斜体」「下線」「リンク」を押して装飾できます。
・リンクは https:// ではじまるURLを入力してください。書き出し時には安全なHTMLタグだけを保持します。
・「プレビューを見る」で確認し、②のZIP書き出しから更新してください。
・公開時は admin.html / admin.js / admin.css をGitHub Pagesにアップロードする必要はありません。管理用としてPCに保存してください。
・以前の作品データや背景・アニメーションはそのまま保持されます。
・管理画面で書き出すZIPには管理用ファイル（admin.html / admin.js / admin.css）は含まれません。管理画面付きの元ZIPをPCに保管してください。


【v17 CONTACTのお問い合わせフォーム】
・お問い合わせフォームには、お名前・返信先メールアドレス・件名・お問い合わせ内容の4欄があります。
・admin.html を開き、ホームページのフォルダーを読み込んで、CONTACTタブを選択します。
・「お問い合わせフォーム：受信先の設定」にメールアドレスを入力し、ZIPを書き出してください。
・入力前は公開ページの送信ボタンが無効になっています。
・GitHub Pagesへは、書き出したZIPの中身（公開用ファイル）をリポジトリ直下にアップロードしてください。
・GitHub Pages自体にメール機能はないため、フォーム送信は外部サービス FormSubmit（https://formsubmit.co/）を使います。
・初めて送信したあと、指定したメールアドレスに届く確認・認証メールを承認しないと、通常の問い合わせメールを受信できません。
・公開後はご自身でテスト送信し、認証を完了してから運用してください。
・送信先アドレスは公開HTMLから第三者も確認可能です。必要なら問い合わせ専用メールを用意してください。
・訪問者が送信すると、FormSubmit側の確認・完了画面に移動します。送信データはFormSubmitを経由します。
・管理画面のファイル（admin.html / admin.js / admin.css）は公開しないでください。
・ORDER、作品表示、画像最適化、キャラクターや背景アニメーションの仕様は維持しています。
